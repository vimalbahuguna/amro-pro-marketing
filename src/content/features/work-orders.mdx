## What it does

A work order is not a thing — it is a sequence of tasks, each performed by a specific person, each signed off against the right license category. AMRO Pro reflects that structure. The system enforces that a category B1 task can't be signed off by someone without that category. It records the tooling and consumables used. It captures findings as structured records linked back to the originating task.

If a corrective action is needed later, the original sign-off is preserved and the corrective work links back to it. No silent overwrites, no "I'll fix it in the next version" data loss.
