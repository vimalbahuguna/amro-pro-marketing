## What it does

The same A-check runs every 600 flight hours. The same lavatory inspection happens every turnaround. Repeating these by hand is how mistakes enter the system. AMRO Pro lets you build templates for any check sequence — pulling from the MPD, from authority guidance, or from operator-specific custom workflows.

Templates are versioned. When a check is applied, the work order records which template version it ran from. If the template changes next month, the historical work order still reflects what was actually done. Templates can be bundled into packages so a full A-check is one button, not 80 individual task additions.
