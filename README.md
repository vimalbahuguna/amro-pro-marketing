# amro-pro-marketing

Marketing site for **AMRO Pro** — enterprise aircraft maintenance, repair &
overhaul (MRO) software with FAA / EASA / CAAC / SACAA workflows baked in.

Astro 6 + Tailwind v4 + MDX. Static output served by nginx on Coolify.

## Local dev

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # static output to dist/
```

## Deployment

Coolify pulls from `origin/main`. Hosted at https://amropro.sosservices.online.

## Brand

- Product name: **AMRO Pro**
- Eyebrow: A Product by SOS Services
- Palette: purple (`purple-700` as primary CTA — matches the parent product card accent)
- Audience: regional carriers, MRO operators, aviation maintenance providers
